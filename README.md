# roshnikobula.com

Portfolio of Roshni Kobula Raja — Next.js 16, React Three Fiber, GSAP, Framer Motion, Lenis, with a Claude-powered "Ask my avatar" chatbot.

```bash
npm install
cp .env.example .env   # add ANTHROPIC_API_KEY
npm run dev
```

Content lives in `src/data/` (`projects.ts`, `resume.ts`, `profile.ts` for the chatbot). Deploy on Vercel: import the repo, set `ANTHROPIC_API_KEY`, attach the domain.
